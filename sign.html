02 · Motion

How it moves

At rest — the sign sways

Only the Λ mark moves: it sways around its base, −5° → 0 → +5° → 0, in a 2.8 s loop. “CRAFTED BY” and the wordmark stay still.

On hover / focus — typing

The wordmark becomes brackets and a red caret, like the site intro, and types the family one after another. Moving away returns it to UzLeeder at once.

The link follows the word on screen. At rest (and on touch screens, where there is no hover) it always opens uzleeder.vercel.app.

type 85 ms / letter→hold 1.1 s→delete 40 ms / letter→pause 0.26 s→next word
  • Brackets and caret are red; the caret blinks once a second. The badge widens smoothly for the longer words — no jump.
  • The sway pauses while it types and continues after.
  • Reduce motion (system setting): no sway, no typing — hover swaps whole words every 1.1 s.
  • Keyboard: Tab focuses it and starts the typing; the link name for screen readers is always “Crafted by UzLeeder”.

04 · Embed code

Add it to a website

Put it at the very end of the site's footer. It renders in its own Shadow DOM — the site's CSS cannot break it and it cannot break the site.

Option 1 — one line (recommended)

    

      
AttributeValues

      
        
themedark (default) · light · auto — follows the visitor's system setting

        
aligncenter (default) · start · end

        
sizemd (default) · sm

        
fontsnone — skip the tiny Outfit font subset (uses the system font)

      
    


    
Option 2 — full code inline (no external request)

    
For sites that must not load scripts from another domain. The same code as crafted.js, pasted into the page.

    


    
Option 3 — plain HTML, static (no script at all)

    
No motion and no typing — only the look. Uses the site's fonts when Outfit is not loaded.

    

  


  
  

    
05 · Rules

    
Use it honestly

    

      
    
        
  • Only on websites UzLeeder really built — for client sites, agreed in the contract or with the client.
    • 
        
  • Small, at the very bottom of the footer: it signs the work, it does not advertise.
    • 
        
  • Use theme to match the site — never recolour it.
    • 
      

      
    
        
  • No crown — it is retired. No other logo in its place.
    • 
        
  • Do not change the colours, the mark, the words or the motion.
    • 
        
  • Not a certification, award or guarantee.
    • 
      

    

    
Privacy
Links to uzleeder.vercel.app. No cookies, no tracking, no analytics. The only external request is the Outfit font subset for the letters it shows — skip it with fonts="none" or Option 3.

    
Not the project signature
The Workspace project signature (UZLEEDER · PROJECT COMPLETED / READY FOR DEPLOYMENT / DEMONSTRATION · PROJECT ID · SALAAM NEW ERA.) is the internal delivery mark on a project record. “Crafted by UzLeeder” is the public signature on a live website.
